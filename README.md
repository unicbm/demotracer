# CS2 DemoTracer Playback

CounterStrikeSharp playback plugin, native runtimes and DTR v12 contracts.
The GUI and converter are maintained privately. Downloads and issues remain here.

As feature complexity and maintenance costs grow, future versions of the desktop
GUI and DemoTracer's own parsing and conversion code are distributed as binaries
to focus development on stability and continued updates. Conversion remains local;
this change does not add an online activation requirement. The server playback
plugin continues under AGPL-3.0-only, with corresponding source available for
released binaries.
