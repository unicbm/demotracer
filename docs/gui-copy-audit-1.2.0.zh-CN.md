# GUI 文案审计验收单（1.2.0）

## 审计范围

本轮覆盖桌面 GUI 的中英文文案与其直接呈现：回放库、设置、更新、环境检测、服务器配置、导出结果、FAQ、日志页和常见空状态。

以下内容不属于本轮改写范围：Demo 或插件返回的原始错误、运行日志正文、协议字段名、命令、文件名、产品名和第三方专有名词。

## 删除标准

- 控件名称已经说明操作时，不再重复解释同一动作。
- 状态标题已经说明结果时，正文只保留下一步或必要边界。
- 不用“建议”“可以”“应当”等助手口吻替代确定事实。
- 不能由当前实现证明的功能描述直接删除或改为真实行为。
- 没有更新说明时明确显示“未提供更新说明”，不生成泛化的“稳定性改进”。
- 删除未被任何界面调用的本地化字段，并由检查脚本阻止它们重新积累。

## 刻意保留

- 饰品导出的 Valve / GSLT 风险确认：这是高风险操作的必要知情边界。
- 覆盖输出、删除归档、强制关闭任务的后果说明：这些操作可能造成数据丢失或不完整输出。
- 安装收据、heartbeat、ABI/API 的文件态与运行态区别：这是判断回放环境是否可信的必要信息。
- 文件类型、数量限制、目标目录和原文件保留说明：这些内容直接影响输入是否合法及数据是否安全。

## GUI 验收位置

1. FAQ：问题数应为 8；答案不再显示无意义的“说明”眉题；无结果状态只保留标题和“清除搜索”。
2. 设置 → 通用：统计说明应直接陈述收集内容，不再出现“可选估算”。
3. 设置 → 主题设置：应显示“自定义 CSS”，未设置背景时只显示“未设置”。
4. 设置 → 桌面应用：卡片只显示 `DemoTracer v版本` 和更新策略，不再重复“桌面应用”。
5. 设置 → 服务器插件配置：未读取状态不再重复解释“读取配置”。
6. English → Settings：一个目录应显示 `1 folder`，零个或多个目录显示 `folders`。
7. 回放库：无匹配结果、空目录和首次使用状态只提供当前事实与可执行动作。
