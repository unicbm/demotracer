# Crosshair preview backgrounds

The seven images are Valve's Counter-Strike 2 settings-preview backgrounds,
from the 1.41.8.8 game resources (2026-10-02):
`panorama/images/crosshair/xhair_{dust2,nuke,mirage,ancient,anubis,cache,inferno}_png.vtex_c`.

They were decoded to PNG and resized from 2560×1440 to 1280×720 WebP
(Lanczos, quality 88) for the desktop preview. The order matches the game menu.
These game images remain Valve's copyrighted assets; the repository's AGPL
license does not relicense them. CS2 DemoTracer is an independent product.
