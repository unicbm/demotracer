## Highlights

- Added a versioned, recoverable GUI preferences file for language, theme, font size, sidebar state, theme customization, and custom CSS profiles, while retaining the WebView cache for startup rendering.
- Extended demo-backed team overlay avatars from library cards into the opened archive scoreboard, with stricter multi-player evidence checks.
- Refined library pagination and context menus, consolidated the player summary layout, and clarified the real-backend GUI acceptance workflow.
- Kept the unchanged Playback/CSS component at v1.1.8; users already on Playback v1.1.8 will not reinstall it.

- 新增可恢复、带版本的 GUI 设置文件，统一保存语言、主题、字号、侧栏状态、主题自定义与自定义 CSS 配置，同时保留 WebView 启动缓存以避免首屏闪烁。
