# CS2 DemoTracer v1.5.3

## 更新内容

- **重构设置页**：移除二级侧栏，采用分组分栏布局；精简视觉层级与留白，说明文案改为按需查看。
- **统一视觉规范**：优化字阶间距、控件尺寸与明暗主题配色，整体界面更紧凑清晰。
- **优化回放库交互**：简化目录入口与搜索筛选，突出「导入 Demo」核心操作。
- **改版准星编辑器**：改为上预览、下参数的上下分栏布局，聚合预览操作并精简文本。
- **清理冗余内容**：移除失效文档入口及已过时的界面说明。

> **升级说明**：本次仅更新 GUI，Playback 组件沿用 1.5.2，无需重新转换已有归档。

## Changes

- **Rework the settings page**: remove the secondary sidebar and arrange settings in grouped columns, with simpler visual hierarchy, tighter spacing and help text available on demand.
- **Unify visual styling**: refine typography, spacing, control sizes and light/dark theme colors for a more compact, clearer interface.
- **Improve the replay library**: simplify folder access, search and filters, and make “Import Demo” the prominent primary action.
- **Redesign the crosshair editor**: place the preview above the settings, group preview controls together and simplify the text.
- **Remove redundant content**: remove the broken documentation link and outdated interface descriptions.

> **Upgrading**: only the GUI needs updating. Playback remains at 1.5.2, and existing archives do not need to be reconverted.
