## Highlights

- Added source Demo data diagnostics. Missing data or shot history is now reported before conversion.
- Unified update notifications for DemoTracer and the CSS plugin. When both need updating, installation can continue after the application restarts.
- Fixed silenced weapon cosmetic models occasionally not being restored correctly during playback.

## 主要更新

- 新增源 Demo 原始数据诊断。解析后若缺少数据或射击历史，会在转换前提示。
- 统一 DemoTracer 与 CSS 插件的更新提示；两者同时更新时，应用重启后可安装。
- 修复消音武器外观模型在回放中偶发未正确恢复的问题。
