# CS2 DemoTracer v1.5.5

- Improve Chinese and English typography, text sizing and spacing for clearer layouts and small text.
- Remove repeated headings and hints, refine sidebar and Settings styling, and simplify import guidance for an empty replay library.
- Update compatibility with the latest CS2 build and fix grenade replay compatibility.
- Reduce runtime overhead when used alongside Bot Improver and improve component switching between normal matches and demo playback.

GUI and Playback now share one release version. Update both, then fully quit and restart CS2.
