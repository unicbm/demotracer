## Highlights

- Added multi-demo library workflows: select or drop up to eight demos, re-analyze duplicates in one queue, browse large libraries with pagination, and show demo-backed team avatars in archive summaries.
- Added PNG workspace backgrounds with adjustable sidebar opacity, together with clearer task, error, update, and archive-status feedback.
- Fixed replay weapon cosmetics, including knife and weapon finish application and fractional glove pattern templates such as Sport Gloves | Kimono.
- Fixed server chat playback and made demo team overlay avatars apply to human players on the matching side, with cleanup after team changes or replay stop.

## 主要更新

- 回放库支持一次选择或拖入最多 8 个 Demo，重复档案可在同一队列中重新分析；大型回放库新增分页，档案摘要会显示 Demo 中可确认的队伍头像。
- 外观设置新增 PNG 工作区背景和侧栏透明度，并改进任务、错误、更新与档案状态提示。
- 修复回放中的刀具与武器皮肤应用，以及小数形式手套图案模板被漏读的问题，例如运动手套 | 和服。
- 修复服务器消息回放；当 Demo 提供统一队伍头像时，加入服务器的真人玩家也会按所属阵营显示该头像，并在换队或停止回放后恢复。
