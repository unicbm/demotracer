# Product integration contracts

This area retains the product's release compatibility contract. Reusable
infrastructure, field declarations and generated data are maintained in the
[`cs2-dtr-common` component](../server/runtime/common/), pinned by the product
and by its component consumers.

| Path | Responsibility |
| --- | --- |
| [`contracts/playback-contract.v1.json`](contracts/playback-contract.v1.json) | Supported GUI/Playback compatibility, format and ABI/API gates |
| [`common/contracts/`](../server/runtime/common/contracts/) | Shared source-field declarations and native host/toolchain pins |
| [`common/econ/`](../server/runtime/common/econ/) | Generated cross-runtime projection of the pinned `@ianlucas/cs2-lib` catalog |
| [`common/csharp/DemoTracerApi/`](../server/runtime/common/csharp/DemoTracerApi/) | Contract-only companion API |
| [`common/native/`](../server/runtime/common/native/) | Shared native utilities and their tests |

The econ projection is generated by the common component's
[`tools/cs2-lib-data/generate-econ-index.mjs`](../server/runtime/common/tools/cs2-lib-data/generate-econ-index.mjs)
from its exact npm dependency and must never be hand-maintained or copied into
consumer repositories. Update common through its own reviewed release, then
align consumer and product gitlinks through their component-update PRs.
Infrastructure source tags do not automatically bump the product's format,
ABI or API versions.
